# Альфа-Партнёр

Презентация проекта **Альфа-Партнёр** — B2B-платформы поиска партнёров и контрагентов внутри клиентской базы банка. Доклад защищает реализацию сервиса внутри Альфа-Босса (Вариант 1) против размещения в общем интернет-банке (Вариант 2).

Один самодостаточный HTML-файл. Никакой сборки, никаких зависимостей, никакого интернета — открывается двойным кликом.

Открыть `alfa-partner.html` в любом современном браузере.

| Действие | Клавиши |

Нажать `P`, затем «Печать → Сохранить как PDF». Размер страницы задан как 1280×720 — получается чистый 16:9 без полей.

## Как это устроено

- **Сквозной транзакционный граф** на Canvas 2D под всеми слайдами. Не перезапускается при смене слайда: слайды — полупрозрачные панели поверх общей среды. В момент перехода две панели накладываются, и фон на мгновение проступает ярче.
- **Направленные переходы**: вперёд слайд входит справа, назад — слева. Вход 620 мс, выход 400 мс — асимметрия делает возврат назад ощутимо быстрым.
- **Анимация работает на смысл**: лента из 30 делений заполняется по дню, числа отсчитываются вверх, таблица проявляется построчно, по рамке ключевой карточки бежит свет на коническом градиенте под маской `mask-composite: exclude`.
- **Анимации идут только на активном слайде**, граф останавливается при уходе со вкладки.
- `prefers-reduced-motion` отключает движение и показывает конечные состояния.
- Браузерные хранилища не используются.

## Шрифт

Фирменный Styrene A лицензионный и в репозиторий не входит. Подключён стек с деградацией: при отсутствии Styrene текст отрисуется системным гротеском (`-apple-system`, `Segoe UI`, `Inter`, `Helvetica Neue`, Arial). Раскладка от этого не ломается.

## Статус данных

Опорные факты доклада: 130 000 клиентов среднего бизнеса, каждый третий ЛПР в Альфа-Боссе, 100% транзакций внутри банка, 18 глубинных интервью, прототип на 22 участниках.

Утверждение «прямой доступ к первому лицу — нет ни у кого» на слайде 5 источником пока не подкреплено.
